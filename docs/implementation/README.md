# Phase 0.12 — Implementation and Mobilization

This package translates the approved architecture of **HRIS for DepEd** into a controlled delivery program. It creates no production implementation.

## Controlling decision

Phase 0.11 issued **CONDITIONAL GO**. Phase 1 may begin only with WP-1 Foundation Baseline Verification after C-01, C-08, C-14 and C-15 are passed and explicit development approval is recorded. Migrations, protected mutations, production deployment and later modules have separate gates.

## Governance rules

- Architecture, development, migration, release and production approvals are distinct.
- Server-side office scope, Laravel Policies, audit and tests precede business modules.
- Technical administrators and developers are not HR or policy approvers by default.
- Policy interpretation, security risk acceptance, migration approval and production deployment remain human decisions.
- Recruitment, appointment, promotion, career progression and reclassification remain separate.

Documents 01–24 comprise the roadmap, governance, strategies, backlog, entry gate and ready-to-paste WP-1 instruction.
