# Decision Records

This folder stores project decisions for the DepEd HRIS.

Use a decision record when a choice affects architecture, security, records, authorization, policy handling, database structure, or long-term maintenance.

Each decision should include date, status, context, decision, alternatives considered, consequences, and follow-up tasks.

Examples include office scoping across Region, Division, District, School, and Implementing Unit; Spatie Permission role structure; Activitylog event naming; service record correction handling; 201 file protection; and report or export auditing.
