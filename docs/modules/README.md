# Module Documentation

This folder will contain documentation for HRIS modules when they are approved for implementation.

Each module document should include module purpose, DepEd users and office scope, policy context, data model, permissions, audit events, workflow states, validation rules, reports and exports, Pest test plan, and open questions.

Expected future module areas include Employees, Plantilla, Recruitment, HRMPSB, Appointments, Promotions, Transfers, Reclassification, Separation, Service Records, Leave Management, Performance Ratings, 201 Files, Reports, Administration, and Audit Trail.

Do not create application features solely because they are listed here. This folder documents approved module plans.
