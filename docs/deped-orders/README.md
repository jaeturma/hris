# DepEd Policy Reference Notes

This folder is for policy-aware implementation notes related to DepEd and government HR requirements.

Relevant policy areas include DepEd hiring, placement, and promotion guidelines, DepEd Order No. 007, s. 2023, DepEd Order No. 020, s. 2024, DepEd Order No. 024, s. 2025, Civil Service Commission rules, Data Privacy Act, and government records management requirements.

Do not quote full legal text in this repository. Store concise summaries, implementation implications, source links, dates checked, and open questions.

When exact rules affect scoring, ranking, qualifications, documentary requirements, retention, or approval authority, verify against current official sources before implementation.
