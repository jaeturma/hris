# Position Profiles

Position profiles connect plantilla and job structure to competency expectations.

## Profile Contents

- Position title
- Salary grade
- Job family
- Plantilla item relationship
- Qualification standards reference
- Required competencies
- Required proficiency levels
- Behavioral indicators
- Office or role context where applicable
- Effective date

## Lifecycle Links

- Recruitment uses the position profile for applicant comparison.
- Placement uses it for position fit.
- Performance uses it for expectations.
- Learning and development uses it for gap closure.
- Promotion and reclassification use it for readiness evidence.
- Succession planning uses it for critical role readiness.
