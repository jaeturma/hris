# Competency Library

The competency library is the managed reference source for competency-based HRM.

## Library Contents

- Competency models
- Core competencies
- Leadership competencies
- Functional or technical competencies
- Competency dictionary entries
- Behavioral indicators
- Proficiency levels
- Effective dates or version markers

## Governance Rules

- Changes to the competency library must be permission-gated.
- Changes must be audit-logged.
- Historical decisions must retain the competency definitions used at the time.
- Competency definitions must avoid vague labels that cannot be assessed.
- Behavioral indicators should be observable and suitable for evidence-based review.
