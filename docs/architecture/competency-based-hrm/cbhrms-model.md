# CBHRMS Model

The Competency-Based Human Resource Management System model connects positions, people, performance, development, promotion, and rewards through shared competency references.

## Core Concepts

- Competency Model
- Core Competencies
- Leadership Competencies
- Functional / Technical Competencies
- Competency Dictionary
- Job Family
- Position Profile
- Position-to-Competency Mapping
- Proficiency Levels
- Behavioral Indicators
- Competency Gap Analysis
- Individual Development Plan
- Learning and Development Intervention
- Succession Planning Readiness
- Promotion Readiness
- Performance Rating Linkage
- Rewards and Recognition Linkage
- Merit Selection Plan Alignment
- SPMS Alignment
- PRAISE Alignment

## Design Principle

A competency should be defined once, mapped to positions, assessed against employees or applicants, and reused across HR lifecycle workflows.
