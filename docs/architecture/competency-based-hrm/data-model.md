# Competency Data Model

This is a conceptual model only. Do not create migrations until a module is approved.

## Reference Entities

- Competency Model
- Competency Dictionary Entry
- Competency Category
- Job Family
- Proficiency Level
- Behavioral Indicator

## Mapping Entities

- Position Profile
- Position-to-Competency Mapping
- Required Proficiency
- Effective-dated Position Requirement

## Transaction Entities

- Competency Assessment
- Assessment Evidence
- Competency Gap Analysis
- Individual Development Plan
- Learning and Development Intervention
- Promotion Readiness
- Succession Planning Readiness
- Rewards and Recognition Evidence

## Design Requirements

- Separate definitions from assessments.
- Preserve historical requirements.
- Link decisions to the competency evidence used.
- Apply office scope, role-based access, and audit logging.
