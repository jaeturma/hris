# Competency-Based HRM Architecture

This folder defines how the DepEd HRIS aligns with CSC PRIME-HRM and the Agency Competency-Based Human Resource Management System direction.

Competency management is a core foundation of the HRIS. It must support recruitment, selection, placement, performance management, learning and development, promotion, reclassification, succession readiness, rewards, recognition, reports, and compliance evidence.
