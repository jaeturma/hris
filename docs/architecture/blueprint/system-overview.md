# System Overview

The DepEd HRIS is a Laravel 13 + React + Inertia + MySQL system for government-grade human resource management across Regional Offices, Schools Division Offices, Districts, Schools, Implementing Units, and Large Schools.

The architecture is founded on:

- DepEd organizational hierarchy and HR operations.
- Civil Service Commission rules and merit principles.
- CSC PRIME-HRM readiness.
- Agency Competency-Based Human Resource Management System alignment.
- Data Privacy Act safeguards.
- Government records management and auditability.

Competency management is a core system foundation. Recruitment, selection, placement, performance management, learning and development, promotion, reclassification, succession readiness, and rewards must be able to reference position profiles and competency evidence.

The system must not be a generic company HR tool. It must support public-sector personnel records, plantilla management, HRMPSB workflows, merit selection, SPMS alignment, PRAISE alignment, and competency-based HR lifecycle decisions.
