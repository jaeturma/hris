# Document Generation

## Purpose

Define versioned templates and generated official documents.

## Template Families

Appointment forms, Service Records, certifications, applicant notices, screening results, evaluation sheets, HRMPSB reports, CAR/CAR-RQA/RQA-style outputs, leave forms, DTR, travel orders, personnel movement notices, competency reports, IDP, PRIME-HRM evidence summaries, and audit reports.

## Required Generation Metadata

Template version, policy version, generated by, generated at, source-record snapshot, output format, document hash, finalization status, signature status, and release status.

## Rules

- Document generation must use versioned templates.
- Generated documents must preserve source-record snapshots.
- Regenerated documents must not silently replace released official copies.
- Draft generated documents and final official records must be distinct.
- If the source record changes after release, issue a corrected/superseding document version rather than overwriting the released copy.

## Source of Truth

The structured source record remains the source of truth for transactions. The generated document is an official output or evidence of the structured record at a point in time.
