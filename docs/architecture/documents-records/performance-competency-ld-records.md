# Performance, Competency, and L&D Records

## Purpose

Define historical records for performance management, competency-based HRM, and learning and development.

## Record Types

Performance plan, performance commitment, rating, validated rating, competency assessment, competency evidence, gap analysis, Individual Development Plan, training nomination, training certificate, learning evaluation, development completion, and promotion-readiness evidence.

## Rules

- These records must be historical and must not overwrite prior cycles.
- Performance ratings used in decisions must be versioned snapshots.
- Competency assessments must preserve framework version, assessor, evidence, and method.
- IDPs consume competency gaps but remain owned by L&D.
- Training certificates are document evidence; completion status is structured L&D data.
- Promotion-readiness evidence must preserve the policy and framework version used.

## Access

Performance and competency records are high or restricted sensitivity. Employee self-service access must be configured per document type and policy.
