# Architecture Documentation

This folder records architecture decisions and design notes for the DepEd HRIS.

Use it for system context, module architecture, office scoping across Region, Division, District, School, and Implementing Unit, database relationship diagrams, authorization and audit architecture, reporting and export architecture, and integration plans.

Do not store temporary implementation notes here. Architecture documents should explain decisions that future maintainers need to understand.

Before creating a new architecture document, check `.codex/architecture.md`, `.codex/database.md`, and `.codex/security.md`.
