# UI Architecture

This folder defines the Phase 0.5 UI/UX planning standard for the DepEd-first, PRIME-HRM-aligned, competency-based HRIS.

This is documentation only. Do not create React pages, components, routes, controllers, models, migrations, or seeders from these documents until the first UI implementation task is approved.

## UI Principles

- Government-grade, clean, professional, modern, accessible, and responsive.
- Built for daily HR operations, not marketing.
- Optimized for DepEd Regional Offices, Schools Division Offices, Implementing Units / Large Schools, HR officers, HRMPSB members, school heads, employees, applicants, and auditors.
- Permission-aware and office-scope-aware from the first screen.
- Sensitive HR records must be visually protected and server-authorized.
- Avoid flashy visuals, excessive gradients, playful motion, or decorative clutter.

## Documents

- `design-system.md`: visual identity, typography, spacing, colors, states, and component standards.
- `application-shell.md`: main shell, sidebar, top bar, breadcrumbs, office switcher, notifications, quick actions.
- `navigation-structure.md`: navigation groups, submenus, users, permissions, and phase priority.
- `dashboard-strategy.md`: role-based dashboard strategy.
- `forms-and-validation.md`: forms, validation, multi-step data entry, and document upload.
- `tables-and-filters.md`: data tables, filters, search, bulk actions, and exports.
- `workflow-screens.md`: UI patterns for recruitment, HRMPSB, promotion, competency, leave, attendance, and document verification workflows.
- `accessibility.md`: accessibility standards.
- `responsive-design.md`: desktop, tablet, and mobile behavior.
