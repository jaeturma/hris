# 15 Executive Dashboard Architecture

## Purpose

Define management dashboards for DepEd HR leadership while protecting individual sensitive data.

## Dashboard Audiences

| Audience | Typical Views | Restrictions |
| --- | --- | --- |
| Regional leadership | Region-wide staffing, vacancies, PRIME-HRM readiness. | Aggregate by division unless detailed access granted. |
| Division leadership | Division/school workforce, hiring cycle status. | Respect school/IU scope and privacy. |
| HR leadership | Operational pipeline and compliance. | Can drill down where authorized. |
| School/IU heads | Assigned school/IU workforce and pending actions. | Own office scope only. |
| Auditors | Evidence, access logs, compliance reports. | Read-only and purpose-bound. |
| Executive management | Trends and risks. | Avoid individual sensitive details by default. |

## Dashboard Principles

Metric definitions are versioned, data freshness is displayed, exports are logged, restricted drill-down requires permission, and AI-generated narratives are labeled advisory.

## Executive Metrics

Vacancy rate, appointment processing aging, HRMPSB cycle aging, competency coverage, IDP completion, performance-rating completion, L&D participation, retirement projection, PRIME-HRM readiness, data-quality alerts, records-completeness rate.
