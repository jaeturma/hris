# Review Module Prompt

Use this prompt for code review of a future HRIS module.

```text
Review this DepEd HRIS module as a senior Laravel, React, Inertia, security, and government HR systems reviewer.

Focus on:
- Correct DepEd domain language and workflows.
- Region, Division, District, School, and Implementing Unit scoping.
- Spatie Permission authorization coverage.
- Spatie Activitylog audit coverage.
- Data Privacy Act risks and sensitive data exposure.
- Government records traceability and history preservation.
- DepEd hiring, placement, promotion, HRMPSB, CSC, and records-management policy awareness where relevant.
- Database constraints, indexes, foreign keys, and MySQL compatibility.
- Inertia props, React TypeScript safety, frontend route helpers, and Vite build risk.
- Pest test coverage, Larastan/PHPStan findings, Laravel Pint formatting, ESLint, and TypeScript checks.

Return findings first, ordered by severity, with file and line references. Then list missing tests, open questions, and a concise summary.
```
